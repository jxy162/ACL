# 08 · 测试与质量保障

## 1. 测试金字塔

```
        ┌────────────────────────┐
        │  端到端 / 集成（少量）    │  真实/桩服务、真实进程启动
        ├────────────────────────┤
        │  服务层测试（中量）       │  下载/版本/Java/认证/启动
        ├────────────────────────┤
        │  领域层单测（大量）       │  纯算法与模型
        └────────────────────────┘
```

- **领域层（Domain）**：纯函数与模型，覆盖率最高，最快。
- **服务层**：用注入的桩（HTTP/文件/进程/时钟）验证行为。
- **集成层**：桩 HTTP 服务器 + 临时文件系统；少量真实端到端（如真实启动一个原版实例）。

## 2. 可测试性设计

- 所有副作用走接口：`IHttpTransport`、`IFileSystem`、`ISystemClock`、`IProcessLauncher`、`IRandomSource`。
- 网络：`IHttpTransport` 用记录-回放桩（录制真实响应为夹具）。
- 文件：内存/临时目录文件系统桩。
- 进程：`IProcessLauncher` 桩（模拟退出码/输出）。
- 时间：`ISystemClock` 固定时钟。

## 3. 测试范围（按服务）

| 服务 | 关键测试点 |
| --- | --- |
| Domain | 版本名比较（`1.13.2`/`1.7.10-pre4`/`1.8_pre`/`1.14 Pre-Release 2`/`26.1-snapshot-1`/`1.14.4 C6`）、Drop/序数编码、组件等价判定 |
| Tasks | 串行/并行/权重进度/取消/重试/失败聚合 |
| Download | 多源取先、断点续传、Range 回退、校验跳过、限速、失败重试 |
| Mirror | 替换表逐条（Assets/Libraries/Meta/Mod） |
| Version | 清单/JSON 解析、`inheritsFrom` 合并、补全计划、篡改检测 |
| Java | 版本解析、32 位拒绝、路径筛除、范围匹配、安装计划 |
| Auth | 设备码 6 步（桩）、刷新、离线 UUID、第三方注入、脱敏 |
| Launch | 参数生成/去重（边界）、natives 按 OS 过滤、dry-run |
| Resources | 搜索/详情/文件、加载器映射、指纹去重、本地解析 |
| Modpack | 各格式样例包 → 安装计划 |
| Diagnostics | 样例日志 → 归因结果 |

## 4. 夹具与样例集

- `tests/fixtures/`：版本清单快照、版本 JSON、加载器元数据、CF/Modrinth 响应、崩溃日志、整合包样例。
- 夹具**版本化**，随外部格式变化更新；夹具更新即回归。
- 网络夹具：录制真实响应（含脱敏），供桩回放。

## 5. 质量门禁（CI）

- `dotnet build` 无警告（内核 `TreatWarningsAsErrors`）。
- `dotnet test` 全绿；核心服务覆盖率阈值（如 Domain ≥ 80%，服务 ≥ 60%）。
- `dotnet format --verify-no-changes` 通过。
- 破坏性契约变更必须有 ADR 且更新文档。

## 6. 手动/探索性测试清单

- 真实登录（微软/离线/第三方）。
- 真实下载（官方 + 镜像、弱网、断点继续）。
- 多加载器组合启动（Forge/NeoForge/Fabric/OptiFine）。
- 多显示器/高 DPI/手柄（UI 阶段）。
- 崩溃归因：导入真实崩溃日志。

## 7. 性能与资源

| 指标 | 目标（示例） |
| --- | --- |
| 元数据请求 | 命中缓存时不发起网络 |
| 下载 | 支持多源并发 + 分片；限速可配 |
| 实例扫描 | 缓存命中时 O(变更) |
| 冷启动 | 可接受上限（待基线测量） |
| 内存 | 长任务无泄漏（下载/监控句柄正确释放） |

## 8. 缺陷分级与响应

| 级别 | 定义 | 处理 |
| --- | --- | --- |
| P0 | 无法启动/数据损坏/安全泄露 | 立即修复 |
| P1 | 主要功能不可用 | 优先修复 |
| P2 | 次要功能/体验问题 | 排期 |
| P3 | 打磨项 | 择机 |
