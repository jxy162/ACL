> **核心原则：参考的是"设计语言"，不是实现。不接入其代码/XAML/资源，也**不得逐像素复刻**（见 [ADR-0011](11-决策记录与变更日志.md)、[ADR-0003](11-决策记录与变更日志.md)）。

## 2. ACL 的原创性要求（必须满足）
必须能与参考界面**并排辨识为不同实现**，至少满足：

1. **布局与栅格自研**：边距 / 圆角 / 字号 / 间距均取 ACL 自有设计令牌，不照抄参考数值。
2. **配色自研**：保留"蓝系 + 深色渐变底"的方向，但色相 / 明度 / 渐变角度 / 辉光位置采用自有取值，形成 ACL 的识别度。
3. **组件自研**：卡片、按钮、导航、弹窗、提示条、进度条等全部以 Avalonia 自行实现（Styles / ControlTemplate / 自绘），不复制参考的模板与命名。
4. **资源自研**：LOGO、壁纸、图标、插画由 ACL 自行生成或自绘；风格可相近，构图与色调必须不同。
5. **交互自研**：页面切换、动效、键盘与手柄导航按 ACL 的交互规范实现。
6. **命名自研**：不沿用参考实现的内部命名与资源键。

## 8. Material 3 Expressive 与动效（2026-10-22 追加）

界面语言升级为 **Material 3 Expressive（M3E）**，并结合 Apple 的"流体界面"原则实现动效。

### 令牌（两套主题共用同一组角色名）
- 颜色角色：`primary / onPrimary / primaryContainer / onPrimaryContainer / secondaryContainer / onSecondaryContainer / surface / surfaceContainerLow|High|Highest / onSurface / onSurfaceVariant / outline / outlineVariant / stateLayerHover|Pressed / indicator`。
- 形状：卡片 28、按钮与徽标 999（药丸）、输入 20、图标底 8~10。
- 排版：Display 42/48、Headline 26/32、Title 24/30、Section 16/22、Body 14/22、Caption 12/18；大字号更紧、正文更松。
- 状态层：hover 约 8% 覆盖、pressed 再加强；按下时按钮缩放 `0.97`（即时反馈）。

### 动效原则（借鉴 Apple *Designing Fluid Interfaces*）
1. **即时反馈**：按下（`Button:pressed`）立刻有视觉反馈，不等松开。
2. **可打断**：页面切换与悬停/按压均用**属性过渡**实现——从当前可见值出发，可被中途重定向，不产生跳变。
3. **克制的编排**：一次只做一处动势（页面切换 300ms `CubicEaseOut`：淡入 + 18px 上移 + 0.985 缩放；反向镜像）。
4. **减弱动效**：设置中可开启（位移归零、时长降至 140ms），供无障碍使用。

### 参考实现的取舍
- 检查过 Avalonia 12 兼容的第三方 UI 库：`Material.Avalonia 3.21.0`、`Irihi.Ursa 2.2.0`、`FluentAvaloniaUI 3.1.0`（均依赖 Avalonia 12.x）。
- 本项目**暂不引入**：M3E 令牌/排版/形状/动效已自研成体系，引入通用 Material 主题会把界面拉回"通用 Material 应用"观感，并可能与本项目令牌冲突。若后续需要库级涟漪、日期选择器等重型控件，可在**不改动令牌体系**的前提下按需引入（例如仅引入特定控件）。

## 9. 动效体系（对齐参考实现的 Fluent 缓动族）

依据 `D:\project\APCL` 的 `ModAnimation`（`AniStart` / `Aa*` 模型与 Fluent 缓动族）在 Avalonia 中**独立重写**：

- **缓动族**（本项目独立命名与实现，数学目标与参考一致）：`AclEaseInSmooth(t^p)`、`AclEaseOutSmooth(1-(1-t)^p)`、
  `AclEaseInOutSmooth`、`AclEaseInBack/OutBack(cos 回弹)`、`AclEaseOutElastic`、`AclEaseInCar`；强度 `Weak=2 / Middle=3 / Strong=4 / ExtraStrong=5`。
- **动画引擎** `Ani`：同名动画组可被打断并从当前值重定向（对齐 `AniStart` 的"重复同名直接停止"），
  支持 `Opacity / Double / Code / PlayAsync(name, specs…)`。
- **应用**：页面切换（内置组合过渡 CrossFade + PageSlide，套用上述缓动）、对话框（淡入 + 上移 + 轻微缩放）、
  轻提示（淡入 + 上移）、卡片悬停（缩放 + 边框）、列表行悬停（背景过渡）、按钮按下即时缩放。

### Avalonia 12 的硬约束（踩坑记录）
1. `Animation.Animators` 中的动画器类型为 **internal**，无法为 `RenderTransform` 注册动画器 → **不要**手写 `Animation` 去动 `RenderTransform`。
2. 直接对 `TranslateTransform/ScaleTransform` 的分量做动画会被框架 `TransformAnimator` 接管并抛
   `InvalidCastException`（要求目标为 `Visual`）→ 位移/缩放请使用**声明式 `Transitions`** 或内置 `PageSlide`。
3. 结论：透明度用 `Ani`，位移/缩放用声明式过渡，页面切换用内置组合过渡；本项目按此实现。
