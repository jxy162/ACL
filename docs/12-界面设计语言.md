# 12 · 界面设计语言

> 目的：为 ACL 的界面（`ACL.App`，Avalonia）定义**原创**的视觉与交互语言。
> 风格参考：本机 `D:\project\APCL` 中已定稿的界面（Material 3 Expressive 风格 + Xbox 风格全屏仪表盘）。
> **核心原则：参考的是"设计语言"，不是实现。不接入其代码/XAML/资源，也**不得逐像素复刻**（见 [ADR-0011](11-决策记录与变更日志.md)、[ADR-0003](11-决策记录与变更日志.md)）。

## 1. 参考风格的要点（仅作方向）
- 深蓝渐变底：柔和径向辉光 + 低透明度等距立方体装饰。
- 大圆角卡片、胶囊按钮与胶囊导航项、克制的投影。
- 自定义标题栏（LOGO + 状态 + 窗口按钮）。
- 主界面：左侧信息/选择列 + 右侧卡片内容 + 底部导航（启动 / 下载 / 设置 / 更多）。
- 全屏「Xbox 仪表盘」：顶部导航 + Hero 主卡片 + 功能卡片入口，支持手柄导航。
- 主色为蓝紫渐变，深色背景。

## 2. ACL 的原创性要求（必须满足）
必须能与参考界面**并排辨识为不同实现**，至少满足：

1. **布局与栅格自研**：边距 / 圆角 / 字号 / 间距均取 ACL 自有设计令牌，不照抄参考数值。
2. **配色自研**：保留"蓝系 + 深色渐变底"的方向，但色相 / 明度 / 渐变角度 / 辉光位置采用自有取值，形成 ACL 的识别度。
3. **组件自研**：卡片、按钮、导航、弹窗、提示条、进度条等全部以 Avalonia 自行实现（Styles / ControlTemplate / 自绘），不复制参考的模板与命名。
4. **资源自研**：LOGO、壁纸、图标、插画由 ACL 自行生成或自绘；风格可相近，构图与色调必须不同。
5. **交互自研**：页面切换、动效、键盘与手柄导航按 ACL 的交互规范实现。
6. **命名自研**：不沿用参考实现的内部命名与资源键。

## 6. 资源来源与补充说明（2026-10-22）

- **LOGO 与壁纸**：使用项目作者**自创**的素材（`logo.png` / `logo.ico` / `wallpaper.png`，来自作者本人的 APCL 工作目录），随 ACL 一同分发；这部分素材版权属作者本人。
- **布局与交互**：常规窗口采用浅色内容面（白色卡片 + 主色渐变按钮 + 底部胶囊导航），全屏采用深色壁纸仪表盘；交互沿用参考实现的习惯（左侧账号/版本/Java、底部导航、下拉选择版本、启动大按钮），但组件与数据绑定均为 ACL 自研。
- **动效**：卡片悬停轻微缩放、导航项背景渐变过渡、页面切换淡入淡出（`CrossFade`）。
