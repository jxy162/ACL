# 03 · 服务设计规范

> 每个服务：**职责 / 接口 / 依赖 / 并发 / 错误 / 扩展点 / 验收**。
> 命名遵循 [02](02-内核架构与模块划分.md)。

## 0. 通用规范

- 异步 API 末位带 `CancellationToken`；长任务接受 `IProgressSink`。
- 进度单调不减（由 `ProgressNode` 保证）。
- 预期失败返回 `Result<T>`；编程错误抛异常。
- 日志经 `IAppLogger`，敏感值脱敏。
- 时间/随机/IO/进程/HTTP 全部可注入。

---

## 1. 任务流水线 TaskPipeline

- **职责**：把复杂流程拆成阶段图，统一进度/取消/重试/失败传播。
- **接口**：`ITaskPipeline.Run(name, stages, ct) → ITaskHandle`；`ITaskStage { Name; Weight; Parallel; ExecuteAsync(ctx, ct) }`。
- **进度**：`ProgressNode` 树按权重加权；对外 `IProgressSink`。
- **并发**：阶段默认串行，`Parallel=true` 与前一阶段并行。
- **错误**：子阶段失败聚合为 `AggregateError`；支持必需/可选阶段。
- **重试**：阶段可声明 `RetryPolicy`（次数/退避/可重试错误码）。
- **验收**：串行/并行/权重/取消/重试/聚合单测；无 `Thread.Sleep`。

## 2. 下载服务 DownloadService

- **职责**：`DownloadItem` → 多源选择 → 分片/整文件 → 断点续传 → 校验 → 落盘。
- **接口**：`DownloadAsync(item, progress, ct)`、`DownloadManyAsync(items, concurrency, …)`。
- **并发**：批次并发（可配）+ 文件内分片并发；全局限速与并发上限。
- **断点续传**：`.part` + 区间记录；不支持 Range → 回退整文件。
- **校验**：`HashSpec`（SHA1/SHA256）；命中即跳过。
- **错误**：单文件重试/切源；批次返回成功/失败/跳过明细。
- **源策略**：按候选序失败切源（见 [11-ADR-0010](11-决策记录与变更日志.md)）。
- **扩展点**：`IMirrorPolicy`、`IFileChecker`、`IDownloadInterceptor`。
- **验收**：多源取先、续传、Range 回退、校验跳过、限速（桩服务）。

## 3. 镜像策略 MirrorPolicy

- **职责**：原始 URL → 有序候选源；决定官方/镜像偏好。
- **接口**：`Resolve(kind, origin)`、`PreferOfficial(kind)`。
- **规则**：见 [05](05-外部接口与生态接入.md) 的替换表；Forge/Fabric/NeoForge 库不加原版源；Assets 强制 HTTPS。
- **扩展点**：`IMirrorProvider`（可插拔）。
- **验收**：替换表逐条单测。

## 4. 版本服务 VersionService

- **职责**：清单/JSON/资源索引获取与解析；生成安装/补全计划；实例读写。
- **接口**：`IVersionCatalog`、`IVersionResolver`、`IInstanceStore`、`IVersionPlanner`。
- **缓存**：清单/JSON 磁盘缓存 + 缓存版本号失效。
- **补全**：校验 jar/assets/assetIndex/libraries，产出 `DownloadItem` 列表。
- **错误**：源缺版本 → 切源；JSON 解析失败 → `VersionParseFailed`。
- **扩展点**：多源清单合并、`IVersionListCache`。
- **验收**：版本名比较、Drop/序数编码、清单解析、补全计划、篡改检测。

## 5. Java 服务 JavaService

- **职责**：探测本机 Java、维护列表、按需求选择或下载安装。
- **接口**：`IJavaProbe`、`IJavaLocator`、`IJavaSelector`、`IJavaInstaller`。
- **探测**：运行 `java -XshowSettings:properties -version`，解析版本/位数/编码；32 位拒绝；结果缓存。
- **搜索**：多目录并行；筛除符号链接指向与特殊路径（`system32`、`javapath_target_*`、`javatmp`）。
- **选择**：`JavaRequirement(VersionRange)` → 已装优先 → 否则按 manifest 安装。
- **验收**：版本解析、位数判定、路径筛除、范围匹配、安装计划。

## 6. 认证服务 AuthService

- **职责**：微软/离线/第三方登录；令牌持久化与刷新。
- **接口**：`IAuthService`、`ISecretProvider`、`ITokenStore`、`IAuthProvider`。
- **微软流程**：设备码 OAuth → XBL → XSTS(+UHS) → MC Token → Profile（6 步），支持刷新。
- **第三方**：Yggdrasil + authlib-injector 注入参数生成。
- **离线**：确定性 UUID。
- **安全**：令牌加密存储；Client ID 经 `ISecretProvider`；日志脱敏。
- **错误**：`InvalidAppRegistration`、`AuthExpired`（自动刷新）、`AuthDenied`。
- **验收**：设备码流/刷新/离线 UUID/第三方注入/脱敏（桩服务器）。

## 7. 启动服务 LaunchService

- **职责**：实例 + 会话 + 选项 → `LaunchPlan`；准备 natives/library；启动进程。
- **接口**：`ILaunchPlanner`、`IProcessLauncher`、`IGameMonitor`、`ILaunchArgumentContributor`。
- **参数**：JVM/Game 生成 + 去重 + 模板替换。
- **准备**：按 OS 过滤解压 natives；库路径收集；`-javaagent` 注入。
- **启动**：进程/工作目录/环境；可选 GPU 偏好（Windows）。
- **监控**：`IGameMonitor` 状态机（预启动/运行/退出/崩溃）、窗口检测、日志解析、退出码归因。
- **错误**：`JavaIncompatible`、参数非法、`ProcessStartFailed`、`GameCrashed`。
- **验收**：参数/去重（含边界）、natives 过滤、dry-run 计划、监控状态机；真实启动做集成测试。

## 8. 资源服务 ResourceService

- **职责**：CurseForge / Modrinth 检索、项目/版本详情、文件解析；本地资源解析。
- **接口**：`IResourceIndex`、`IProjectDetails`、`IFileResolver`、`ILocalResourceScanner`。
- **鉴权**：CurseForge 需 `x-api-key`；Modrinth 免鉴权。
- **映射**：加载器类型 ↔ CurseForge `ModLoaderType`；MC 版本 ↔ 资源版本。
- **本地**：jar 内 `fabric.mod.json` / `mods.toml` / `mcmod.info` 等解析。
- **错误**：限流（429）退避；鉴权失效明确错误码。
- **验收**：搜索/详情/文件、映射、指纹去重、本地解析。

## 9. 整合包服务 ModpackService

- **职责**：识别并安装多种整合包格式。
- **接口**：`IModpackInstaller` + `IModpackFormatHandler`。
- **格式**：CurseForge、Modrinth、HMCL、MMC、MCBBS、LauncherPack、通用压缩包。
- **流程**：解压 → 解析清单 → 解析依赖 → 组装安装计划 → 交 Version/Download → 复制 overrides。
- **错误**：加载器不兼容 → 明确提示并可跳过。
- **验收**：每种格式样例包解析为预期安装计划。
- **实现现状（2026-10-22）**：已实现 Modrinth（modrinth.index.json）、CurseForge（manifest.json，文件需经 CF 接口按 projectID/fileID 解析）、通用压缩包（兜底）；HMCL / MMC / MCBBS 待实现；加载器自身安装（Forge/NeoForge installer 或补丁释放）待实现。

## 10. 诊断服务 DiagnosticsService

- **职责**：采集日志、规则式崩溃归因、生成可分享报告。
- **接口**：`ICrashAnalyzer`、`IDiagnosticsExporter`、`ICrashRule`。
- **规则**：关键错误、堆栈关键字、Mod 名猜测 → 结构化 `CrashReason` + 文本报告。
- **扩展点**：可插拔规则与关键词库。
- **验收**：样例日志 → 期望归因。

## 11. 配置服务 ConfigurationService

- **职责**：强类型配置读写、分实例覆盖、迁移、加密字段。
- **接口**：`IConfigurationStore`、`IConfigSchema<T>`、`IConfigMigrator`。
- **存储**：JSON；加密字段用受保护存储（DPAPI/平台密钥链）。
- **验收**：读写/默认值/分实例/加密/迁移。

## 12. 日志服务 LoggingService

- **职责**：结构化日志、级别过滤、轮转、脱敏、宿主桥接。
- **接口**：`IAppLogger`、`ILogSink`。
- **要点**：后台写线程；UI 动作由宿主实现；脱敏器可配置。
- **验收**：轮转/级别/脱敏/并发写。

## 13. 更新服务 UpdateService（可延后）

- **职责**：检查更新、下载、自替换重启。
- **接口**：`IUpdateService`、`ICdnResolver`。
- **验收**：版本比较、下载、替换路径。

## 14. 遥测 Telemetry（可延后，默认关闭）

- **职责**：匿名统计/故障上报（**必须可关闭且默认最小化**）。
- **约束**：脱敏；隐私合规；见 [09](09-安全隐私与合规.md)。
