# 09 · 安全、隐私与合规

## 1. 安全原则

- **HTTPS 默认开启**；仅在明确理由下提供关闭开关，并在 UI 明示风险。
- **文件校验**：下载文件按 SHA1/SHA256 校验；版本 JSON/清单做完整性检查。
- **最小权限**：只读写必要目录；不请求无关系统权限。
- **防路径穿越**：解压/整合包安装严格校验目标路径在实例目录内。

## 2. 密钥与令牌

| 凭证 | 来源 | 存储 |
| --- | --- | --- |
| Microsoft Client ID | `ISecretProvider`（环境变量/配置/CI secrets） | 配置（非机密，但仍不建议硬编码） |

> **来源（ADR-0013）**：使用**本项目作者本人申请**的密钥，读取顺序为 (1) 启动器目录下的便携文件 ACL.secrets.json，(2) 环境变量 ACL_MS_CLIENT_ID / ACL_CURSEFORGE_API_KEY。ACL **不与任何其他启动器共享或互通密钥机制**；ACL.secrets.json 已在 .gitignore 中，切勿提交。仓库内仅提供占位示例 ACL.secrets.example.json。
| CurseForge API Key | `ISecretProvider` | 受保护存储 |
| 访问/刷新令牌 | 登录流程 | **加密存储**（DPAPI / libsecret / Keychain） |

规则：
- **禁止**把密钥/令牌提交到仓库；CI 用 secrets。
- 日志、遥测、崩溃报告中**脱敏**（用户名、令牌、绝对路径、Key）。
- 提供"退出登录"清除令牌。

## 3. 依赖与第三方

- 每个依赖记录到 `THIRD-PARTY-NOTICES`（名称、版本、许可、来源 URL）。
- 优先许可宽松（MIT/BSD/Apache）的依赖；评估体积与维护活跃度。
- 定期检查依赖安全公告。

## 4. 隐私与遥测

- 遥测**默认关闭**且可随时关闭；开启时**最小化采集**并脱敏。
- 崩溃报告分享前脱敏，提供"仅本地保存"选项。
- 在设置/关于页说明采集内容与用途。

## 5. 净室与合规（自研的关键）

ACL 是**净室自研**：不复制任何第三方启动器源码，只依据**公开规范**（Mojang/加载器/资源站/认证服务的官方文档）与**外部可观察行为**实现。

**必须遵守**：
1. **不复制代码**：不粘贴、不改写他方源码；参考仅限公开协议与行为。
2. **不沿用命名**：不使用既有启动器的内部命名、资源标识作为本项目的命名。
3. **独立实现**：算法与结构独立设计（见 [02](02-内核架构与模块划分.md)、[03](03-服务设计规范.md)）。
4. **署名与致谢**：在"关于"页/文档致谢所参考的公开规范、数据来源与灵感来源；对 Minecraft/Mojang/Microsoft 的商标与政策予以尊重。
5. **不捆绑侵权资源**：不内置/分发 Minecraft 本体或受版权保护的付费内容；仅按官方协议下载。

> 说明：净室自研使本项目**不受**特定启动器许可的"派生/命名"约束；但**尊重原创、给出署名**仍是基本原则。
> 相关研究记录见 [10-参考实现研究](10-参考实现研究-PCL与ACL架构剖析.md)。

## 6. 平台政策

- **Mojang/Microsoft**：调用 Minecraft 服务需应用审核；未过审不得宣称可用正版登录。
- **CurseForge/Modrinth**：遵守其 API 使用条款与限流。
- **商标**：不暗示与任何官方/第三方过度关联。

## 7. 发布合规

- 分发物包含 `LICENSE` 与 `THIRD-PARTY-NOTICES`。
- 发布说明注明数据来源与免责声明。
