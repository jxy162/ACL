## 术语

| 术语 | 含义 |
| --- | --- |
| **ACL** | 本项目：完全自研的 Minecraft 启动器（正式名称） |
| **内核 (Core)** | 与 UI 无关的核心能力：版本/下载/Java/认证/启动/资源/诊断 |
| **服务 (Service)** | 内核中承担单一职责、可独立测试与替换的组件 |
| **宿主 (Host)** | 承载内核的界面或 CLI（`ACL.App` / `ACL.Cli`） |
| **PCL / PCL2** | Plain Craft Launcher 2（第三方启动器），**仅作为架构参考** |
| **APCL / AliCraftLauncher** | 本机上的既有 PCL 派生项目，**仅作为架构参考** |
| **净室 (Clean-room)** | 只依据公开规范与外部行为独立实现，不复制他方源码 |
| **加载器 (Loader)** | Forge / NeoForge / Fabric / LiteLoader / OptiFine / Quilt 等 |
