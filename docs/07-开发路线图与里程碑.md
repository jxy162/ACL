# 07 · 开发路线图与里程碑

> 原则：小步交付、每阶段可独立运行与测试、优先打通"最小可用启动链路"。
> 阶段编号与 [03-服务设计规范](03-服务设计规范.md) 的服务对应。

## 总览

| 阶段 | 主题 | 关键产出 | 验证方式 |
| --- | --- | --- | --- |
| M0 | 立项与文档 | 本目录文档、ADR | 评审 |
| M1 | 骨架与任务引擎 | Abstractions + Domain + Tasks | 单测 |
| M2 | 下载与镜像 | DownloadService + MirrorPolicy | 桩服务集成 |
| M3 | 版本与实例 | VersionService + InstanceStore | 单测 + 真实元数据 |
| M4 | 认证 | AuthService（MS/离线/第三方） | 桩 + 手动 |
| M5 | Java | JavaService | 单测 + 手动 |
| M6 | 启动与监控 | LaunchService + GameMonitor | 集成（真实启动） |
| M7 | 资源与整合包 | ResourceService + ModpackService | 单测 + 样例包 |
| M8 | 界面与 CLI | ACL.App（Avalonia）+ ACL.Cli | 端到端 |
| M9 | 诊断、迁移与发布 | Diagnostics + 迁移 + CI + 发布 | 回归 |

## 里程碑判定

| 里程碑 | 组成 | 达成标志 |
| --- | --- | --- |
| **Kernel-α** | M1+M2+M3 | 读版本并 **dry-run** 出完整下载计划 |
| **Kernel-β** | M4+M5+M6 | 从零**登录并干净启动**原版实例 |
| **Kernel-γ** | M7+M8 | **安装整合包**并在 UI/CLI 启动 |
| **ACL-1.0** | M9 | 迁移/诊断/CI/文档/发布齐备 |

## 各阶段细节

### M1 骨架与任务引擎
- 交付：`ACL.Core.Abstractions`、`ACL.Core.Domain`、`ACL.Core.Tasks`。
- 验收：版本名比较（含 pre/rc/snapshot/experimental）覆盖用例；Drop/加载器/OptiFine 序数单测；任务引擎串行/并行/权重/取消/重试/聚合全绿；**无 `Thread.Sleep`**。
- 风险：进度语义偏差 → 以"单调、可加权、可观测"为准。

### M2 下载与镜像
- 交付：`DownloadService`、`MirrorPolicy`、`IDownloadInterceptor`。
- 验收（桩 HTTP）：多源取先、断点续传、Range 回退、校验跳过、限速；替换表逐条与 [05](05-外部接口与生态接入.md) 一致。

### M3 版本与实例
- 交付：`VersionCatalog`、`VersionResolver`、`InstanceStore`、`VersionPlanner`。
- 验收：解析真实清单/JSON；`inheritsFrom` 链合并；补全计划 dry-run；篡改检测与组件等价判定。

### M4 认证
- 交付：`AuthService`（设备码 6 步 + 刷新 + 离线 + 第三方注入）。
- 验收：桩服务器跑通令牌链；脱敏；`InvalidAppRegistration` 明确错误码。
- 风险：Mojang 审核（外部）→ 过审前用离线/桩验证。

### M5 Java
- 交付：`JavaProbe`、`JavaLocator`、`JavaSelector`、`JavaInstaller`。
- 验收：多版本判定、32 位拒绝、路径筛除、范围匹配、manifest 安装计划。

### M6 启动与监控
- 交付：`LaunchPlanner`、`ProcessLauncher`、`GameMonitor`。
- 验收：参数生成/去重（边界）、natives 按 OS 过滤、dry-run 计划、监控状态机；真实启动成功。
- 风险：加载器组合多样 → 组合矩阵测试。

### M7 资源与整合包
- 交付：`ResourceIndex`（CF/Modrinth）、`ModpackInstaller`（CF/Modrinth/HMCL/MMC/MCBBS/LauncherPack/压缩包）。
- 验收：搜索/详情/文件；各格式样例包产出预期安装计划；限流退避。

### M8 界面与 CLI
- 交付：`ACL.App`（Avalonia，MVVM）+ `ACL.Cli`。
- 验收：CLI 端到端；UI 通过事件/进度订阅内核，界面不含业务逻辑。

### M9 诊断、迁移与发布
- 交付：`CrashAnalyzer` 规则库、数据迁移器、CI、发布流水线、文档定稿。
- 验收：崩溃样例归因正确；旧数据迁移幂等可回滚；CI 全绿。

## 优先级取舍（资源有限时）

1. **必做**：M1 → M2 → M3 → M5 → M6（下载 + 启动）。
2. **重要**：M4（认证；可先离线/第三方过渡）。
3. **次之**：M7（资源/整合包）、M9 诊断。
4. **可延后**：遥测、更新服务、跨平台打包。

## 风险登记（Top）

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 认证需应用审核 | 正版登录受阻 | 过审前用离线/第三方；清晰引导 |
| 镜像不稳定 | 下载失败 | 多源 + 回退 + 可配置 |
| 版本格式变化 | 解析失败 | 适配层 + 回归样例集 |
| 加载器组合复杂 | 启动失败 | 组合矩阵 + dry-run 校验 |
| 平台差异 | 跨平台问题 | Platform 抽象 + 分层测试 |
