# 05 · 外部接口与生态接入

> 本文列出 ACL 需要打交道的**外部契约**：请求什么、如何鉴权、如何镜像、如何回退。
> 具体 URL 可能变化，实现时以官方文档为准；此处为**契约摘要**。

## 1. 源策略

每个请求都有"官方源 + 镜像源"的有序候选：

- `IMirrorPolicy.Resolve(kind, origin) → IReadOnlyList<Uri>`：返回有序候选（含官方与镜像）。
- `PreferOfficial(kind)`：文件下载 / 版本列表可分别配置偏好。
- 下载时**并发取先返回者**，失败自动切源。

镜像提供方（可插拔）：

| 镜像 | 域名 | 说明 |
| --- | --- | --- |
| BMCLAPI | `bmclapi2.bangbang93.com` | 社区加速（bangbang93） |
| MCIM | `mod.mcimirror.top` / `files.mcimirror.top` | 社区加速 |
| 自定义 | 用户配置 | 通过 `IMirrorProvider` |

## 2. Minecraft 官方与镜像

| 用途 | 官方 | BMCLAPI 重写 |
| --- | --- | --- |
| 版本清单 | `launchermeta.mojang.com/mc/game/version_manifest*.json` | `bmclapi2.bangbang93.com/mc/game/version_manifest.json` |
| 版本 JSON / Meta | `piston-meta.mojang.com`、`launcher.mojang.com`、`launchermeta.mojang.com` | 主机替换为 `bmclapi2.bangbang93.com` |
| Libraries | `libraries.minecraft.net`、`piston-data.mojang.com` | `.../maven` 与 `.../libraries`（双候选） |
| Assets | `resources.download.minecraft.net`、`piston-data/meta` | `bmclapi2.bangbang93.com/assets` |
| Java Runtime | `.../v1/products/java-runtime/.../all.json` | `bmclapi2.bangbang93.com/v1/...` |

**规则**：Libraries 若属于 Forge/Fabric/NeoForge 等第三方库，**不加原版源**（走镜像 maven）；Assets 的 `http://` 强制升级 `https://`。

## 3. 加载器元数据

| 加载器 | 官方 | BMCLAPI |
| --- | --- | --- |
| Forge | `maven.minecraftforge.net`、`files.minecraftforge.net/.../promos` | `bmclapi2.bangbang93.com/forge/minecraft[/<ver>]`、`/forge/promos` |
| NeoForge | `maven.neoforged.net/api/maven/versions/releases/net/neoforged/{forge,neoforge}` | `bmclapi2.bangbang93.com/neoforge/meta/api/maven/details/releases/net/neoforged/{forge,neoforge}` |
| Fabric | `meta.fabricmc.net/v2/versions` | `bmclapi2.bangbang93.com/fabric-meta/v2/versions` |
| Quilt | `meta.quiltmc.org/v3/versions` | 视镜像支持情况 |
| LiteLoader | `meta.liteloader.com`（maven 元数据）| `bmclapi2.bangbang93.com/maven/com/mumfrey/liteloader/versions.json` |
| OptiFine | `optifine.net/`、`/adloadx`、`/downloads`、`/changelog` | `bmclapi2.bangbang93.com/optifine/`、`/optifine/versionList` |

- OptiFine 需要**哈希库**（识别/校验安装包）与**补丁释放**（安装器内嵌资源）。
- 加载器安装常需运行其 installer 或解压补丁：内核需支持"补丁释放 + 参数注入"。

## 5. 认证

### 5.1 Microsoft

| 项 | 说明 |
| --- | --- |
| 模式 | OAuth 2.0 **设备码流** |
| scope | `XboxLive.signin offline_access` |
| Client ID | `ISecretProvider`（环境变量/配置/CI secrets） |
| 重定向 | `http://localhost`（本机回环回调） |
| 令牌链 | OAuth → XBL(`XBL3.0`) → XSTS(+UHS) → MC Token → Profile(UUID/Name) |

**合规**：调用 Minecraft 服务需应用经 Mojang 审核；未过审时令牌链第 4 步失败（`InvalidAppRegistration`）——需在 UI 给出清晰引导。

### 5.2 第三方 / 离线

- **third-party**：Yggdrasil API + `authlib-injector`（`-javaagent:authlib-injector.jar=<apiRoot>`）。
- **offline**：按用户名生成确定性 UUID。

## 6. 更新与 CDN

- `ICdnResolver`：解析下载 URL 的 CDN 占位/前缀（可配置）。
- `IUpdateService`：检查更新 → 下载 → 自替换重启（独立进程/参数）。

## 7. 请求层

- `IHttpTransport` 统一封装；支持重试、超时、条件请求、浏览器头模拟。
- HTTP 磁盘缓存（等价 CacheCow：新鲜度 + 条件请求）。
- 限流退避（429/5xx）。
- 代理支持（系统代理 / 手动配置）。

## 8. 系统能力（平台层）

| 能力 | 平台 | 说明 |
| --- | --- | --- |
| 注册表 | Windows | 系统信息/环境检测 |
| GPU 偏好 | Windows | 为可执行文件设置 GPU 偏好 |
| 内存优化 | Windows | 可选 |
| 窗口置顶/句柄 | Windows | 由 UI 层处理 |
| 密钥链 | 全平台 | DPAPI / libsecret / Keychain |
