# 02 · 内核架构与模块划分

> 内核 = `ACL.Core.*` + `ACL.Application` + `ACL.Infrastructure` + `ACL.Platform.*`；**界面与 CLI 不属于内核**。

## 1. 内核边界

**属于内核**：
- 版本识别、解析、比较、安装清单与补全。
- 资源下载（多源/分片/断点/校验/镜像）。
- Java 探测/选择/安装。
- 认证（微软/离线/第三方）与令牌管理。
- 启动计划生成、natives 准备、进程启动与监控。
- 社区资源检索、整合包安装。
- 崩溃归因、诊断导出。
- 配置、日志（抽象与默认实现）。

**不属于内核**：
- 任何 UI 控件、页面、动画、主题、对话框。
- 平台强绑定的交互（窗口句柄、DPI、剪贴板 UI）。
- 面向用户的具体文案（内核用**错误码 + 资源键**，文案在宿主）。

## 3. 解耦机制

1. **进度**：所有长任务接受 `IProgressSink`，通过 `Report(stage, fraction, message)` 上报；UI/CLI 各自渲染。
2. **取消**：所有异步 API 末位带 `CancellationToken`。
3. **事件**：状态变化用事件（如 `IGameMonitor.StateChanged`），宿主订阅。
4. **结果**：预期失败返回 `Result<T>`（含 `ErrorCode`），非预期抛异常。
5. **选项对象**：`LaunchOptions` / `InstallOptions` / `ModpackOptions` 显式传参，替代全局设置读取。
6. **上下文**：`IMinecraftContext`（游戏目录/实例）与登录态显式传入。
7. **接口归位**：仅依赖 BCL/基础类型的跨切面抽象置于 Abstractions；签名依赖领域模型的服务接口与实现同工程（见 [11-ADR-0009](11-决策记录与变更日志.md)）。

## 4. 线程与异步模型

- 统一 `async/await` + `Task`；**禁止 `Thread.Sleep` 轮询**（改 `Task.Delay`/信号）。
- CPU 密集用 `Task.Run`；下载用 `IAsyncEnumerable`/并发限流。
- 取消必须协作式传播；`OperationCanceledException` 是正常控制流，不记为错误。
- UI 线程派发由宿主负责；内核回调可能在任意线程（文档需注明）。

## 5. 错误模型

```csharp
public enum ErrorCode {
    None = 0,
    Network, Timeout, HashMismatch, NotFound, MirrorUnavailable,
    AuthExpired, AuthDenied, InvalidAppRegistration,
    JavaMissing, JavaIncompatible,
    VersionParseFailed, ManifestCorrupt,
    ProcessStartFailed, GameCrashed,
    ConfigInvalid, IoError, Canceled, Unknown
}
public readonly record struct Result<T>(T? Value, ErrorCode Code, string? Detail = null) {
    public bool IsSuccess => Code == ErrorCode.None;
}
```

- `ErrorCode` 稳定、可枚举；`Detail` 仅用于日志/诊断，**不直接展示给用户**。
- 宿主把 `ErrorCode` 映射为本地化文案。

## 6. 扩展点（插件友好）

| 扩展点 | 用途 |
| --- | --- |
| `IMirrorProvider` | 新增镜像源（BMCLAPI/MCIM/自定义） |
| `IModpackFormatHandler` | 新增整合包格式 |
| `IFileChecker` | 自定义校验策略 |
| `IAuthProvider` | 新增认证方式（如新的第三方） |
| `ICrashRule` | 新增崩溃归因规则 |
| `IDownloadInterceptor` | 重写请求（URL/头），如 CF `x-api-key`、镜像替换 |
| `ILaunchArgumentContributor` | 追加/修改启动参数 |

> 扩展点以接口注册，**不改内核代码即可扩展**。

## 7. 命名与版本

- 命名空间：`ACL.Core.*` / `ACL.Application` / `ACL.Infrastructure` / `ACL.Platform.*` / `ACL.App` / `ACL.Cli`。
- 内核各工程独立 **SemVer**；对外契约（Abstractions）破坏性变更需主版本递增并记录 ADR。
- 公共 API 变更须：更新 XML 注释 + 兼容性检查 + 记入 [11](11-决策记录与变更日志.md)。

## 8. 内核"不做什么"清单（红线）

- ❌ 不引用 Avalonia/WPF/WinForms/Console。
- ❌ 不直接读全局静态设置（必须注入）。
- ❌ 不弹窗、不写 Console、不播放音效。
- ❌ 不硬编码密钥（必须 `ISecretProvider`）。
- ❌ 不使用 `Thread.Sleep` 驱动状态。
- ❌ 不在日志中输出令牌/用户名原文。
